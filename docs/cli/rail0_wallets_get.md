## rail0 wallets get

Fetch a single wallet (by id, 0x address or @alias)

```
rail0 wallets get <wallet> [flags]
```

### Examples

```
  rail0 wallets get 0xABCD…
```

### Options

```
  -h, --help   help for get
```
