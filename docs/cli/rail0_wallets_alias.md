## rail0 wallets alias

Save a unique address-book alias for an address (like 'aliases add', args reversed)

```
rail0 wallets alias <address> <name> [flags]
```

### Examples

```
  rail0 wallets alias 0xAbC123… payee
```

### Options

```

```
